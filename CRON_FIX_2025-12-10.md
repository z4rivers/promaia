## Technical Details

### Why System Python Works
- System Python has full disk access by default
- Cron runs with limited permissions in macOS
- Virtual environment files trigger security restrictions
- System Python bypasses these restrictions while maintaining functionality

### Alternative Solution (Not Used)
Grant cron Full Disk Access via System Settings → Privacy & Security → Full Disk Access
- More complex to configure
- Requires system-level changes
- Not necessary since system Python works fine
