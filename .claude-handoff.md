### Key Research Findings
- `pip install libsql` (v0.1.11) — supports Windows, embedded replicas, BUT:
  - Does NOT support `enable_load_extension()` — cannot load sqlite_vec
  - Does NOT support `row_factory` — existing SmartRow wrapper still needed
  - Does NOT support cursor iteration — must use fetchall/fetchone
- **Native libSQL vectors replace sqlite-vec entirely**: `F32_BLOB(768)`, `vector_distance_cos()`, `vector_top_k()`
- Schema already uses native libSQL syntax but runtime uses `import sqlite3 as libsql` + `sqlite_vec` — split personality
- Migration: `vec_distance_cosine()` → `vector_distance_cos()` in 6+ query files
- Turso free tier: 5GB storage, 500M reads/mo — more than enough
- Turso CLI installs in WSL only (not native Windows): `curl -sSfL https://get.tur.so/install.sh | bash`
- Import existing DB: `turso db create zbrain --from-file ./promaia.db` (requires WAL mode first)
- WSL is Ubuntu 24.04, Python 3.12.3, bare system install — no project packages installed
- promaia.db is at Windows path, accessible from WSL at `/mnt/c/Users/Zachary Turner/dev/promaia/promaia.db`
