# v3.0 Plan 5-01: Fix Blockers + Deploy to Render

## Objective
Get Promaia running on Render so the dashboard is accessible from Zack's phone and agents run 24/7.

## Tasks

### Task 1: Fix requirements.txt for cloud deployment
**Files:** `requirements.txt`
- Remove or make `uvloop` conditional (Linux-only, will crash on some platforms)
- Add `tzdata` (required for timezone support outside Windows)
- Verify `runtime.txt` specifies a Python version Render supports (3.12.x)

### Task 2: Push zbrain branch to GitHub
**Commands:**
- `git push -u origin zbrain`
- Verify branch visible at github.com/commodorebob/promaia

### Task 3: Create Render web service
**Manual steps (Zack):**
1. Sign up / log in at render.com
2. New > Web Service > connect GitHub repo (commodorebob/promaia)
3. Branch: zbrain
4. Render auto-detects render.yaml blueprint
5. Plan: Starter ($7/mo) — must be paid for always-on

### Task 4: Set environment variables on Render
**Required env vars:**
- `DATABASE_URL` — Supabase connection string (already have it)
- `GOOGLE_API_KEY` — Gemini models + embeddings
- `TELEGRAM_BOT_TOKEN` — from BotFather
- `TELEGRAM_WHITELIST` — allowed chat IDs
- `DASHBOARD_PASSWORD` — activates auth (choose a password)
- `PYTHON_ENV=production` — secure cookies, proxy trust
- `TELEGRAM_WEBHOOK_URL` — set to `https://<service-name>.onrender.com`

**Optional:**
- `DASHBOARD_USERNAME` (default: admin)
- `DEEPGRAM_API_KEY` (voice notes — not needed, Gemini handles transcription now)

### Task 5: Verify from phone
1. Open `https://<service-name>.onrender.com` on phone browser
2. Login page appears → enter credentials → dashboard loads
3. Send Telegram message → bot responds (webhook mode)
4. Wait for scheduled agent run → verify it fires
5. Check `/api/health` returns `{"status": "healthy", "auth": "enabled"}`

## Acceptance Criteria
1. Dashboard loads from phone browser with auth
2. Telegram bot responds to messages via webhook
3. Scheduler fires agents on schedule (morning briefing, email triage, evening digest)
4. PC can be off and system keeps running

## Estimated Effort
- Code fixes: 15 min
- Render setup: 30 min (includes env vars)
- Verification: 15 min
