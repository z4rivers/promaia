**A) Create `promaia/agents/cost_tracker.py`:**

1. **CostRecord dataclass** with fields: agent_name, model_id, task_type, input_tokens, output_tokens, cached_tokens, thinking_tokens, cost_usd, execution_id (int), created_at (datetime).

2. **CostTracker class** with:
   - `__init__()`: Calls `_ensure_table()` to create brain.agent_costs if not exists.
   - `_ensure_table()`: Uses `pg_connect()` from `promaia.storage.postgres_db` to run CREATE TABLE IF NOT EXISTS for brain.agent_costs and its indexes. Follow the exact pattern in execution_tracker.py for connection management.
   - `log_call(record: CostRecord)`: INSERT into brain.agent_costs. Use `%s` parameter substitution (psycopg2 style, matching existing codebase patterns).
   - `compute_cost(model_config: ModelConfig, usage: dict) -> float`: Takes a ModelConfig (from model_router.py) and a usage dict with keys: input_tokens, output_tokens, cached_tokens, thinking_tokens. Computes:
     - non_cached_input = input_tokens - cached_tokens
     - input_cost = non_cached_input * input_price_per_m / 1_000_000
     - cached_cost = cached_tokens * input_price_per_m * cached_input_discount / 1_000_000
     - output_cost = output_tokens * output_price_per_m / 1_000_000
     - thinking_cost = thinking_tokens * thinking_price_per_m / 1_000_000
     - Return sum. (Thinking tokens billed separately per research -- usage_metadata.thoughts_token_count)
   - `get_daily_spend() -> float`: SUM(cost_usd) WHERE created_at >= CURRENT_DATE.
   - `get_run_spend(execution_id: int) -> float`: SUM(cost_usd) WHERE execution_id = %s.
   - `get_daily_summary(days: int = 7) -> list[dict]`: GROUP BY date, agent_name with COUNT, SUM tokens, SUM cost. Return list of dicts.

Append the brain.agent_costs table definition after existing tables. Include:
```sql
CREATE TABLE IF NOT EXISTS brain.agent_costs (
    id SERIAL PRIMARY KEY,
    execution_id INTEGER REFERENCES agent_executions(id),
    agent_name TEXT NOT NULL,
    model_id TEXT NOT NULL,
    task_type TEXT,
    input_tokens INTEGER DEFAULT 0,
    output_tokens INTEGER DEFAULT 0,
    cached_tokens INTEGER DEFAULT 0,
    thinking_tokens INTEGER DEFAULT 0,
    cost_usd REAL NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_agent_costs_agent ON brain.agent_costs (agent_name, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_agent_costs_date ON brain.agent_costs (created_at DESC);
CREATE INDEX IF NOT EXISTS idx_agent_costs_execution ON brain.agent_costs (execution_id);
```
