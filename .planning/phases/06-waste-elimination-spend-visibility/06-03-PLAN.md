**A) Create `promaia/agents/gemini_executor.py`:**

1. **GeminiExecutor class:**
   - `__init__(self, cost_tracker: CostTracker, router: ModelRouter)`: Store references. Create `genai.Client(api_key=os.getenv("GOOGLE_API_KEY"))`. Import `from google import genai` and `from google.genai import types` (already used in nl_orchestrator.py, so the import pattern is established).

   - `async def generate(self, model_config: ModelConfig, system_instruction: str, contents: str, execution_id: int, agent_name: str, task_type: str = "synthesize", thinking_budget: int = None) -> dict`:
     - Build `types.GenerateContentConfig` with:
       - `system_instruction=system_instruction`
       - `temperature=model_config.temperature` (will be 1.0 per user decision)
       - If thinking_budget AND model_config.max_thinking_budget > 0: add `thinking_config=types.ThinkingConfig(thinking_budget=min(thinking_budget, model_config.max_thinking_budget))`
     - Call `self.client.models.generate_content(model=model_config.model_id, contents=contents, config=config)`
     - Extract usage from `response.usage_metadata`:
       - `input_tokens = usage.prompt_token_count`
       - `output_tokens = usage.candidates_token_count`
       - `cached_tokens = getattr(usage, 'cached_content_token_count', 0) or 0`
       - `thinking_tokens = getattr(usage, 'thoughts_token_count', 0) or 0`
     - Compute cost via `self.cost_tracker.compute_cost(model_config, usage_dict)`
     - Log via `self.cost_tracker.log_call(CostRecord(...))`
     - Return dict: content (response.text), input_tokens, output_tokens, cached_tokens, thinking_tokens, cost_usd, model (model_config.model_id)

   - `async def generate_with_fallback(self, ..., fallback_enabled: bool = True) -> dict`:
     - Same signature as generate but wraps in try/except
     - On exception (API error, rate limit, etc.): if fallback_enabled, get fallback model from `self.router.get_fallback_model(current_model_key)`. If fallback exists, retry with fallback model. If no fallback, re-raise.
     - Log fallback attempts: `logger.warning(f"Falling back from {model} to {fallback}")`
     - This implements ROUTE-02.

   **NOTE:** The `google.genai` client uses synchronous methods by default. The `generate_content` call is synchronous -- use `await asyncio.to_thread(self.client.models.generate_content, ...)` to keep the event loop non-blocking, or just call it directly since the existing executor already blocks during API calls. Match the existing pattern -- check how nl_orchestrator.py calls it.

**B) Create `promaia/agents/budget_guard.py`:**

1. **BudgetGuard class:**
   - `__init__(self, cost_tracker: CostTracker, per_run_cap: float = 0.50, daily_cap: float = 2.00)`: Store tracker and caps.
   - `can_start_run(self, agent_name: str, is_critical: bool = False) -> tuple[bool, str]`: Returns (allowed, reason). If is_critical, always True. Otherwise, check daily spend from CostTracker. Return (False, "Daily budget exceeded: $X.XX/$Y.YY") if over.
   - `check_run_budget(self, execution_id: int) -> tuple[bool, str]`: Check per-run spend. Return (False, "Run budget exceeded: $X.XX/$Y.YY") if over.

2. **RunawayDetector class:**
   - `__init__(self, max_iterations: int = 5, max_cost: float = 0.50, similarity_threshold: float = 0.85)`: Store limits.
   - `check(self, response_text: str, cost: float) -> tuple[bool, str]`: Returns (should_kill, reason).
     - Track responses list and total_cost
     - Kill if: iterations > max_iterations, total_cost > max_cost, last 3 responses are similar (word overlap > threshold)
   - `_responses_similar(self, responses: list) -> bool`: Word-set overlap check (simple, no dependencies).
   - `reset(self)`: Clear state for new run.

Both classes should import from `promaia.agents.cost_tracker` and `promaia.agents.model_router`.
