   - Return the count of events inserted.
   - Wrap all DB operations in try/except -- event emission must never crash the agent pipeline. Log warnings on failure.
   - Import `get_postgres_db` from `promaia.storage.postgres_db`, `json` from stdlib.

   - After the `logger.info("Agent completed successfully")` line and before the `return` statement, add:
     ```python
     # Step 7: Emit routable events (EVENT-07)
     try:
         event_count = emit_agent_events(

             output=result.get('output', ''),
             execution_id=execution_id,
         )
         if event_count > 0:

     ```
   - This goes in the success path only (NOT in the except/failure path). Event emission failure must not affect the agent result.
