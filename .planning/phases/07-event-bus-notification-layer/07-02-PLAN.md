1. Create `promaia/events/channels.py`:
   - `NotificationChannel` ABC with:
     - `name` property (abstract, returns str) -- channel identifier like 'dashboard', 'telegram'
     - `async deliver(self, event: dict) -> bool` (abstract) -- deliver event, return True on success
     - `supports_urgency(self, urgency: str) -> bool` (abstract) -- whether channel handles this urgency level
   - `DashboardChannel` concrete implementation:
     - `name` returns `"dashboard"`
     - `supports_urgency` returns True for `interrupt` and `digest` (not `archive` -- archive events are just logged)
     - `deliver` marks the event as routed in the DB: `UPDATE brain.events SET routed_at = NOW(), channel = 'dashboard' WHERE id = %s`. Returns True. Dashboard delivery is passive (the badge query picks up unrouted events), so "delivering" really just means marking it as dashboard-bound. This is a bookkeeping operation.
   - Import ABC, abstractmethod from abc. Import get_postgres_db from promaia.storage.postgres_db.

2. Create `promaia/events/rate_limiter.py`:
   - `RateLimiter` class with `__init__(self, max_per_hour: int = 10, cooldown_minutes: int = 30)`
   - Method `allow(self, channel_name: str, urgency: str) -> bool`:
     - `interrupt` urgency always allowed (bypass rate limiting -- urgent events must go through)
     - For non-interrupt: check hourly count via SQL: `SELECT COUNT(*) FROM brain.events WHERE routed_at IS NOT NULL AND channel = %s AND routed_at > NOW() - INTERVAL '1 hour'`. If >= max_per_hour, deny.
     - For non-interrupt: check cooldown via SQL: `SELECT MAX(routed_at) FROM brain.events WHERE routed_at IS NOT NULL AND channel = %s AND urgency != 'interrupt'`. If less than cooldown_minutes ago, deny.
     - DB is source of truth (not in-memory state) -- survives scheduler restarts per research pitfall 5.
   - Import get_postgres_db, datetime, logging.

3. Create `promaia/events/router.py`:
   - `EventRouter` class with `__init__(self, poll_interval: int = 30)`:
     - Initialize `self.channels: list[NotificationChannel]` with `[DashboardChannel()]`
     - Initialize `self.rate_limiter = RateLimiter()`
     - Store `self.poll_interval = poll_interval`
     - Store `self.user_timezone = "America/New_York"` (hardcoded for now, per research recommendation to use env var with this default)
   - `async run(self)` -- main polling loop:
     - Log "Event router started (polling every {poll_interval}s)"
     - `while True`: fetch unrouted events, route each, sleep poll_interval
     - Wrap loop body in try/except (log error, continue) -- router must never crash the scheduler
   - `_fetch_unrouted_events(self) -> list[dict]`:
     - Query: `SELECT id, type, payload, source, urgency, created_at, held_until FROM brain.events WHERE urgency IS NOT NULL AND routed_at IS NULL AND (held_until IS NULL OR held_until <= NOW()) ORDER BY CASE urgency WHEN 'interrupt' THEN 1 WHEN 'digest' THEN 2 WHEN 'archive' THEN 3 END, created_at ASC`
     - Uses get_postgres_db().fetch_all()
   - `async _route_event(self, event: dict)`:
     - If urgency is `archive`: mark routed immediately (UPDATE brain.events SET routed_at = NOW(), channel = 'archive' WHERE id = %s). Return. Archive events skip channels entirely.
     - Check quiet hours via `_is_quiet_hours()`. If quiet and urgency is not `interrupt`: set `held_until` to next 6am local time and return. Interrupt events bypass quiet hours.
     - For each channel in self.channels:
       - Skip if not channel.supports_urgency(event urgency)
       - Check rate_limiter.allow(channel.name, event urgency). If denied, log and skip.
       - Call await channel.deliver(event). Log success/failure.
   - `_is_quiet_hours(self) -> bool`:
     - Use `zoneinfo.ZoneInfo(self.user_timezone)` to get current local time
     - Quiet hours: hour >= 21 or hour < 6
   - `_hold_for_morning(self, event_id: int)`:
     - Calculate next 6am in user timezone
     - `UPDATE brain.events SET held_until = %s WHERE id = %s`
   - Import: asyncio, logging, datetime/timedelta, zoneinfo.ZoneInfo, get_postgres_db, json, DashboardChannel/NotificationChannel from channels, RateLimiter from rate_limiter
