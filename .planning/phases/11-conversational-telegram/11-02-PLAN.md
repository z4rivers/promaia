```python
"""
Free-text message handler for Telegram bot.

Routes all non-command text messages through the conversation engine
for Gemini-powered responses using brain context.
"""
import logging

from aiogram import Router
from aiogram.types import Message

from promaia.telegram.conversation import generate_response, reset_synthesis_timer
from promaia.telegram.formatting import send_long_message

logger = logging.getLogger(__name__)

router = Router()


@router.message()
async def handle_free_text(message: Message) -> None:
    """Route all free-text messages through the conversation engine."""
    text = message.text
    if not text:
        return

    # Show typing indicator while Gemini thinks
    await message.bot.send_chat_action(message.chat.id, "typing")

    # Generate conversational response (handles session, impact scoring, context, Gemini)
    response = await generate_response(message.chat.id, text)

    # Reset synthesis timer (background -- never blocks response)
    await reset_synthesis_timer(message.chat.id)

    # Send response (handles splitting at 4096 char limit)
    await send_long_message(message, response)
```

Key changes from current messages.py:
- Remove `_is_greeting()`, `_is_question()`, `_GREETING_PATTERNS`, `_GREETING_RESPONSES` -- greetings and questions now go through Gemini which handles them naturally per the personality prompt
- Remove import of `capture_memory` and `detect_mode` -- conversation.py handles capture internally
- Add import of `generate_response` and `reset_synthesis_timer` from conversation.py
- Add import of `send_long_message` from formatting.py (for long Gemini responses)
- Add typing indicator before Gemini call (per Research pitfall 2 -- user needs feedback while waiting)
- Call `reset_synthesis_timer()` after each message (debounced synthesis timer)

2. **`async def reset_synthesis_timer(chat_id: int) -> None`** -- Public function called by handlers after each message.
   - Cancel any existing timer for this chat_id (try/except CancelledError)
   - Check if message count threshold is reached: query the current session's message_count from brain.conversation_sessions. If message_count >= SYNTHESIS_MESSAGE_THRESHOLD, run synthesis immediately via `asyncio.create_task(_run_synthesis(chat_id))` and return
   - Otherwise, start a new silence timer: `_synthesis_timers[chat_id] = asyncio.create_task(_synthesis_countdown(chat_id))`

3. **`async def _synthesis_countdown(chat_id: int) -> None`** -- Internal. Waits SYNTHESIS_SILENCE_SECONDS (240s), then calls `_run_synthesis(chat_id)`. Wrapped in try/except CancelledError (normal -- timer was reset by new message).

4. **`async def _run_synthesis(chat_id: int) -> None`** -- Internal. The actual synthesis logic:
   a. Get the current session via get_or_create_session() (should return the active one)
   b. Get all session messages via get_session_messages()
   c. If fewer than 3 messages, skip synthesis (not enough substance per CONV-05: "3+ messages")
   d. Format session messages into a transcript: "User: ...\nAssistant: ...\n..."
   e. Call Gemini with a SYNTHESIS prompt (separate from the personality prompt):
      ```
      system_instruction: "You are a session summarizer. Produce a concise synthesis of this conversation. Focus on: decisions made, commitments stated, emotional context, project updates, and ideas worth revisiting. If meaning of earlier messages changed with later context, note that. Be specific -- names, projects, dates. 2-4 sentences max."
      contents: the session transcript
      ```
   f. Use `client.aio.models.generate_content` with model="gemini-3-flash-preview", temperature=0.3 (lower for factual synthesis)
   g. Store the synthesis as a permanent memory via `capture_memory(synthesis_text, domain="conversation-synthesis")` -- this gives it an embedding for future semantic search
   h. Update the session via `update_session_synthesized(session_id, memory_id)`
   i. Log: "Session {session_id} synthesized: {synthesis_text[:100]}..."
   j. Clean up: remove chat_id from _synthesis_timers dict
   k. Wrap everything in try/except -- synthesis failure must NEVER crash the bot. Log and continue.

5. **`async def cleanup_stale_sessions() -> None`** -- Public function for bot startup. Checks brain.conversation_sessions for any sessions where synthesized=FALSE and last_message_at is more than SYNTHESIS_SILENCE_SECONDS ago. Runs synthesis for each. This handles the case where the bot restarted and orphaned timer tasks (per Research pitfall 3).

Wrap cost logging in try/except -- never fail a response due to cost tracking errors.
