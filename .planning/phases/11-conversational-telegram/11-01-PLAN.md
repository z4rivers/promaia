1. **schema.sql** -- Append two new table definitions at the end of schema.sql (after brain.agent_costs):

```sql
-- brain.conversations: ephemeral session history for continuity
CREATE TABLE IF NOT EXISTS brain.conversations (
    id SERIAL PRIMARY KEY,
    chat_id BIGINT NOT NULL,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
    content TEXT NOT NULL,
    impact_score REAL DEFAULT 0.0,
    promoted BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_conversations_chat_session
    ON brain.conversations (chat_id, session_id, created_at ASC);

CREATE INDEX IF NOT EXISTS idx_conversations_chat_recent
    ON brain.conversations (chat_id, created_at DESC);

-- brain.conversation_sessions: tracks session lifecycle and synthesis state
CREATE TABLE IF NOT EXISTS brain.conversation_sessions (
    id SERIAL PRIMARY KEY,
    chat_id BIGINT NOT NULL,
    session_id TEXT NOT NULL UNIQUE,
    started_at TIMESTAMPTZ DEFAULT NOW(),
    last_message_at TIMESTAMPTZ DEFAULT NOW(),
    message_count INTEGER DEFAULT 0,
    synthesized BOOLEAN DEFAULT FALSE,
    synthesized_at TIMESTAMPTZ,
    synthesis_memory_id INTEGER REFERENCES brain.memories(id)
);

CREATE INDEX IF NOT EXISTS idx_conv_sessions_chat
    ON brain.conversation_sessions (chat_id, started_at DESC);
```

2. **brain_ops.py** -- Add six new async functions at the end of the file (after `get_projects`). Import `uuid` at the top of the file.

All six functions follow the established pattern: define a `_sync()` inner function that uses `_get_db()`, wrap in `asyncio.to_thread(_sync)`.

- `async def save_conversation_message(chat_id: int, session_id: str, role: str, content: str, impact_score: float = 0.0) -> int` -- Inserts a row into brain.conversations. Also updates brain.conversation_sessions: increments message_count and sets last_message_at to NOW(). Returns the conversation message id.

- `async def get_conversation_history(chat_id: int, limit: int = 10) -> list[dict]` -- Fetches last N messages from brain.conversations for this chat_id ordered by created_at ASC (chronological). Returns list of dicts with keys: role, content, created_at.

- `async def get_or_create_session(chat_id: int, gap_minutes: int = 30) -> str` -- Checks brain.conversation_sessions for the most recent session for this chat_id. If the most recent session's last_message_at is within gap_minutes of now AND the session is not yet synthesized, returns that session_id. Otherwise creates a new session with a uuid4 session_id. Returns the session_id string.

- `async def update_session_synthesized(session_id: str, memory_id: int) -> None` -- Marks a session as synthesized: sets synthesized=TRUE, synthesized_at=NOW(), synthesis_memory_id=memory_id.

- `async def get_session_messages(session_id: str) -> list[dict]` -- Fetches ALL messages for a given session_id ordered by created_at ASC. Used by synthesis to get the full session content. Returns list of dicts with keys: role, content, impact_score, created_at.

- `async def promote_message_to_memory(conversation_id: int, content: str, domain: str = None) -> int` -- Inserts the content into brain.memories (same pattern as capture_memory but simpler -- no action extraction). Sets source='telegram-conversation'. Updates the brain.conversations row to set promoted=TRUE. Returns the memory_id.

No "how's your day going?" openers. No pleasantry padding. Open with something useful.

The system prompt must include:
   - Core identity: "You are Promaia. You are a stakeholder in Zack's life -- invested in his projects and goals. You show up working."
   - SUBSTANCE-FIRST directive: "Open every response with something useful -- a deliverable, a key question, a ready step, or a connection. Never open with pleasantries, small talk, or 'how are you?' filler. Warmth comes through in HOW you deliver substance, not in padding before it."
   - Attitude: Invested (track his projects, notice drift), Direct (say the thing, no diplomatic filler), Curious (walk through doors his words open), Challenging (reframe assumptions, point out wrong problems)

   Keep it UNDER 300 words total. Short = more effective with Gemini per D4.

**Functions:**

1. `def score_impact(text: str, known_projects: list[str] = None) -> float` -- Synchronous. Heuristic-based impact scoring (NOT Gemini per D2). Five dimensions:
   - Entity detection: dates, days of week, months, dollar amounts, "tomorrow", "next week", "by end of" (regex)
   - Action language: "I need to", "I decided", "I'm going to", "don't forget", "we should", "deadline", "remind me" (regex)
   - Emotional markers: "frustrated", "excited", "worried", "proud", "stressed", "love", "hate" etc. (regex)
   - Project name mentions: check text against known_projects list (case-insensitive)
   - Length/specificity: word_count > 20 gets 0.15, > 50 gets additional 0.10

   Each dimension fires independently and adds to a cumulative score. BUT: require at least 2 signals to fire (if only 1 signal and score < 0.3, halve the score -- prevents false positives per Research pitfall 5). Return min(score, 1.0).

2. `async def _assemble_context(chat_id: int, user_message: str) -> str` -- Maximalist context assembly per D1. Build in this order (most important first for Gemini attention):
   - User profile: top 15 profile rows by confidence from brain.profile, formatted as "## About Zack\n- field: value"
   - Conversation history: last 10 messages via get_conversation_history(), formatted as "## Recent Conversation\nUser: ...\nAssistant: ..."
   - Relevant memories: semantic search (top 5) against user_message using VectorDBManager + pgvector query. Format as "## Relevant Memories\n- content[:200]". Wrap in try/except -- degrade gracefully if embedding fails.
   - Active projects: from brain.contexts JOIN brain.domains WHERE is_project=true, format as "## Active Projects\n- P{priority} name: state"
   - Pending actions: from brain.actions WHERE status='pending', format as "## Pending Actions\n- description"

   Use asyncio.to_thread() for ALL sync DB calls (same as brain_ops.py pattern). Return the concatenated context string.

3. `async def generate_response(chat_id: int, user_message: str) -> str` -- The main entry point. Flow:
   a. Get or create session via get_or_create_session()
   b. Score the user message impact via score_impact() (pass known projects from _get_known_projects())
   c. Save user message to conversations via save_conversation_message()
   d. If impact_score >= IMPACT_PROMOTION_THRESHOLD, promote to brain.memories via promote_message_to_memory()
   e. Send typing indicator: NOT done here (caller handles it)
   f. Assemble context via _assemble_context()
   g. Call Gemini via client.aio.models.generate_content with:
      - model="gemini-3-flash-preview"
      - contents=f"{context}\n\nUser: {user_message}"
      - config=types.GenerateContentConfig(system_instruction=PERSONALITY_SYSTEM_PROMPT, temperature=1.0)
   h. Extract response text. If empty or error, return a graceful fallback ("I'm having trouble thinking right now. Try again?")
   i. Save assistant response to conversations (impact_score=0 for assistant messages)
   j. Return the response text

   Wrap the Gemini call in try/except with a 30-second timeout (asyncio.wait_for). Log any errors.

4. `def _get_known_projects() -> list[str]` -- Sync helper that queries brain.domains WHERE is_project=true, returns list of project names. Used by score_impact. Cache for 5 minutes to avoid repeated DB calls (simple module-level cache with timestamp).

**Do NOT implement the synthesis timer in this task.** That belongs in Plan 02 where it integrates with the handler lifecycle.
