# v3.0 Plan 6-01: Category Tabs + Interactive Dashboard

## Objective
Transform the dashboard into a life command center with category filtering, health/finance domains, interactive actions, and project drill-down.

## Tasks

### Task 1: SQL Migration — Health + Finance Domains
**Files:** `promaia/brain/migrations/006_life_dashboard_categories.sql`
- INSERT `health` and `finance` domains into brain.domains
- CREATE `brain.health_metrics` (id, metric_type, value, note, created_at)
- CREATE `brain.finance_entries` (id, entry_type, name, amount, frequency, note, created_at)
- Seed known subscriptions: Railway Volumes Pro ($27.49), Claude Max ($199), Google AI ($20)
- Idempotent (ON CONFLICT DO NOTHING)

### Task 2: Category Tab System
**Files:** `promaia/web/templates/dashboard.html`
- Horizontal tab bar: All | Projects | Health | Finance | Email
- Client-side JS switching (display:none/block, no page reload)
- Badge counts on Projects and Email tabs
- Styled with existing Superflat CSS custom properties

### Task 3: Enhanced Projects View
**Files:** `promaia/web/routers/dashboard.py`, `promaia/web/templates/dashboard.html`, new `promaia/web/templates/project_focus.html`
- Project cards: name, status (active/stale/paused), last activity, pending action count
- Status: active (< 7 days), stale (7-14 days), paused (> 14 days) based on brain.contexts.last_touched
- Drill-down: `/projects/<slug>` showing project memories, actions, context, standing directive

### Task 4: Health + Finance Panels
**Files:** `promaia/web/routers/dashboard.py`, `promaia/web/templates/dashboard.html`
- Health: 4 metric cards (sleep, exercise, stress, energy) with last value + trend arrow
- Health: quick-log form (type/value/note)
- Finance: subscription tracker with monthly total
- Finance: agent cost summary (today/7d/total from brain.agent_costs if exists)
- Finance: expense log form

### Task 5: Interactive Elements
**Files:** `promaia/web/routers/dashboard.py`, `promaia/web/templates/dashboard.html`
- Quick capture bar at top of dashboard (text input, submits to brain capture)
- Action completion checkboxes (click → POST → strikethrough)
- Toast notification system for feedback

### Task 6: API Endpoints
**Files:** `promaia/web/routers/dashboard.py`
- `POST /api/capture` — quick capture from dashboard
- `POST /api/actions/<id>/complete` — mark action done
- `GET /api/dashboard/category/<name>` — filtered data for tab switching
- `POST /api/health/log` — log a health metric
- `POST /api/finance/log` — log a spending entry

## Acceptance Criteria
1. Tab switching feels instant (client-side, preloaded data)
2. Can drill into any project and see its full context
3. Can complete actions with a checkbox click
4. Can quick-capture a thought from the dashboard
5. Health metrics show last recorded value with trend
6. Finance shows subscription total and agent costs
7. Responsive — usable on phone browser

## Estimated Effort
- SQL migration: 15 min
- Dashboard UI: 2-3 hours
- API endpoints: 30 min
- Testing: 30 min
