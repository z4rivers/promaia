    **handlers/voice.py** -- Voice note transcription pipeline:
    - Create aiogram Router with a handler filtered on `lambda msg: msg.voice is not None`
    - Handler flow:
      1. Check if `DEEPGRAM_API_KEY` is set. If not, reply "Voice transcription unavailable -- DEEPGRAM_API_KEY not configured." and return.
      2. Check `message.voice.file_size` -- if over 10MB, reply "Voice note too large (max ~10 minutes)." and return.
      3. Download voice file via `bot.get_file(message.voice.file_id)` then `bot.download_file(file.file_path, buffer)` into a `BytesIO` buffer.
      4. Send audio bytes to Deepgram: `AsyncDeepgramClient().listen.rest.v("1").transcribe_file({"buffer": audio_bytes, "mimetype": "audio/ogg"}, {"model": "nova-3", "smart_format": True})`. Note: the exact SDK 6.x API may differ -- check the deepgram-sdk 6.0.1 API surface. The key is to use the async pre-recorded transcription endpoint. Deepgram accepts OGG Opus natively (no conversion needed).
      5. Extract transcript from response: `response.results.channels[0].alternatives[0].transcript`
      6. If transcript is empty, reply "Could not transcribe the voice note." and return.
      7. Reply with "Heard: {transcript}" so Zack can verify the transcription.
      8. Call `capture_memory(transcript)` from brain_ops.py to auto-capture the transcribed text.
      9. Reply with the capture result.
    - Wrap the Deepgram call in try/except -- on failure, reply "Transcription failed. Try again?" and log the real error.

    **channel.py** -- TelegramChannel(NotificationChannel):
    - Implements the `NotificationChannel` ABC from `promaia/events/channels.py`
    - Constructor takes `bot_token: str` and `chat_id: int`. Creates its own `Bot(token=bot_token)` instance internally. This decouples it from the main bot process -- the event router runs in the scheduler process, which is separate. Two processes can use the same bot token (Telegram allows multiple API calls; only one can poll for updates, but sending is stateless).
    - `name` property returns `"telegram"`
    - `supports_urgency(urgency)` returns True for "interrupt" and "digest"
    - `deliver(event)` method:
      1. Extract `summary` from `event["payload"]` (JSONB, may need json.loads if still a string). Fall back to `str(event.get("payload", "New notification"))`.
      2. Format: "URGENT: {summary}" for interrupt, just "{summary}" for digest.
      3. Call `await self._bot.send_message(self._chat_id, text)`.
      4. Mark event as routed: `UPDATE brain.events SET routed_at = NOW(), channel = 'telegram' WHERE id = %s`
      5. Return True on success, False on failure. Log errors but never raise.
    - Important: The `deliver()` method needs to handle the Bot session lifecycle. Since this Bot instance only sends (never polls), it should work without a persistent session. If aiogram requires explicit session management for send, create an aiohttp session on first deliver and close it on error.

    **bot.py** -- Update to include voice router:
    - Add `from promaia.telegram.handlers import voice` to imports
    - Insert `dp.include_router(voice.router)` AFTER commands.router and BEFORE messages.router. The registration order must be: commands (specific filters), voice (voice filter), messages (catch-all). This prevents the catch-all from intercepting voice notes.

    **router.py** -- Register TelegramChannel:
    - Import: `import os` and `from promaia.telegram.channel import TelegramChannel`
    - In `EventRouter.__init__()`, after the DashboardChannel, conditionally add TelegramChannel:
      ```python
      telegram_token = os.getenv("TELEGRAM_BOT_TOKEN")
      telegram_whitelist = os.getenv("TELEGRAM_WHITELIST", "")
      if telegram_token and telegram_whitelist:
          chat_id = int(telegram_whitelist.split(",")[0].strip())
          self.channels.append(TelegramChannel(bot_token=telegram_token, chat_id=chat_id))
      ```
    - This uses the first whitelisted chat ID as the push target. The channel is only registered if both token and whitelist are configured, so the event router degrades gracefully if Telegram is not set up.
    - Guard the import with try/except ImportError in case aiogram is not installed -- log a warning and skip Telegram channel registration.
