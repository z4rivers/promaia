<task type="auto">
  <name>Task 2: Create brain/engine.py with 8 deterministic functions</name>
  <files>promaia/brain/engine.py</files>
  <action>
Create `promaia/brain/engine.py` with 8 deterministic functions. CRITICAL: No LLM calls inside any of these functions. Pure Python + SQL via PostgresDB.

1. `detect_mode(message: str) -> dict` — Returns `{mode: str, confidence: float}`. Uses keyword/phrase heuristics to classify user intent:
   - "working" keywords: build, implement, code, fix, create, deploy, commit, run
   - "planning" keywords: plan, think about, consider, design, architect, should we, what if
   - "capturing" keywords: remember, note, capture, save, don't forget, I need to
   - "reviewing" keywords: review, check, look at, status, how's, briefing, summary
   Default to "working" with confidence 0.3 if no match. Return highest-confidence mode.

2. `confirm_mode(detected: str, current: str) -> str` — If detected != current, return a natural confirmation string like "Sounds like we're planning — I'll explore options before making changes. Right?" For each mode, have a distinct confirmation phrase. If same mode, return empty string.

3. `enforce_guardrails(action: str, source: str) -> bool` — Returns True if action is allowed. Block: "main" or "master" branch operations, "send" + "email"/"message"/"slack", "delete" + critical patterns, "merge" + "pr"/"pull request". Allow everything else. Source parameter distinguishes "heartbeat" (strict) from "session" (lenient).

4. `track_time(session_id: str, domain_id: int, db=None) -> float` — Query `brain.events` for the earliest event with this session_id and domain_id, return elapsed seconds since then. If no events found, return 0.0. Use `get_postgres_db()` if db is None.

5. `budget_check(cycle_id: str, max_budget: float = 1.0, db=None) -> dict` — Query `brain.events` where source='heartbeat' and session_id=cycle_id, count API calls (type='api_call'), sum payload->>'cost' values. Return `{remaining: float, exceeded: bool, calls: int}`.

6. `save_context(session_id: str, domain_id: int, db=None) -> dict` — Insert a snapshot into `brain.events` with type='context_save', payload containing domain_id, timestamp, and a JSON snapshot of the current brain.contexts row for that domain. Return the snapshot dict.

7. `restore_context(session_id: str, db=None) -> dict` — Query the most recent 'context_save' event, parse and return its payload. Return empty dict if none found.

8. `suggest_next(domains: list, energy: str = None, db=None) -> dict` — Given a list of domain dicts (from brain.contexts + brain.domains), score each by: staleness (days since last_updated / stale_threshold_days, capped at 2.0), priority (inverse, so priority 1 scores highest), and energy adjustment (if energy='low', halve scores for high-effort items marked priority <= 3). Return `{domain: str, action: str, score: float, reason: str}` for the top pick. If energy is None, skip energy adjustment.

Import pattern: `from promaia.storage.postgres_db import get_postgres_db`. Accept optional `db` parameter in functions that do SQL so they're testable with mocks.
  </action>
