# v3.0 Vision: One Brain, Every Surface

**Defined:** 2026-03-07
**Origin:** First real user test + design conversation with Zack

## North Star

Promaia is the persistent memory and personality layer that makes any AI session — Claude Code, Claude app, Telegram, web — feel like one continuous relationship. The intelligence lives in the data (profile, memories, context, projects), not in any single model or interface.

## Architecture Principles

1. **Brain is a standalone API.** Any LLM can call it. Not coupled to Claude.
2. **Gemini for cost-effective conversation.** Telegram bot uses Gemini with brain context injected. Pennies per message.
3. **Claude is a premium surface, not a dependency.** Claude Code and Claude app connect via MCP (covered by Max subscription). No Claude API costs for core functionality.
4. **For other users:** Gemini key (free tier) + Railway Volumes (free tier) = working system.
5. **One personality manifest.** Every surface loads the same behavioral identity from the brain.
6. **Hybrid capture.** Raw messages stored for searchability. Conversation sessions also produce synthesized takeaway memories.

## What "Working Product" Means

- ONE command starts everything
- Morning briefing arrives even if you turn the computer on late
- Telegram feels like talking to someone who knows you
- Voice notes get intelligent responses, not "Captured."
- Web dashboard is your life command center — always on, accessible from phone
- The system tells you when it's online and offline
- Every surface shares the same knowledge and personality
