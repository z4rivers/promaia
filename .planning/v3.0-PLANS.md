## Plan 3: Conversational Telegram Bot (Gemini-Powered)
**Effort:** 3-4 hours | **Impact:** THE core product change

### Goal
Telegram bot responds like a person who knows you — powered by Gemini with brain context.

### Tasks
1. Create `promaia/telegram/conversation.py`:
   - `generate_response(user_message, user_id)` function
   - Loads ~200 token profile prefix from brain (name, preferences, tone, current projects)
   - Loads last 10 messages from conversation history for continuity
   - Calls Gemini Flash with: system prompt (personality) + profile prefix + recent context + user message
   - Returns conversational response string
2. Create `brain.conversations` table:
   - Columns: id, chat_id, role (user/assistant), content, created_at
   - Stores both user messages and bot responses for continuity
   - Used for conversation session grouping
3. Update `handlers/messages.py`:
   - After capture (keep the brain write), call `generate_response()` for the reply
   - Store both user message and bot response in conversations table
4. Update `handlers/voice.py`:
   - Same flow: transcribe → capture → generate conversational response
5. Create personality system prompt:
   - Currently hardcoded in conversation.py (TODO: move to brain as profile trait or config)
   - Defines tone, warmth, directness calibrated to Zack's preferences
   - Includes: "You are Promaia. You know this person deeply..."
6. Hybrid capture synthesis:
   - After 4 minutes of no messages, if there were 3+ messages in the session, trigger Gemini to synthesize a summary memory
   - Tag as `source: telegram-synthesis`, link to raw message IDs

### Acceptance
- Text "how are my projects looking?" → get a real answer using brain context
- Voice note about a project idea → intelligent acknowledgment, not "Captured."
- 5 messages back and forth → one synthesized memory created after conversation ends
- Response latency < 3 seconds
