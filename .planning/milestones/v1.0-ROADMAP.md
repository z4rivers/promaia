## Milestone Summary

**Key Decisions:**
- Supabase over local Postgres (iPhone day-1 access)
- pgvector over ChromaDB (cloud-native, SQL-queryable)
- Gemini for cheap tasks, Opus for reasoning (cost optimization)
- Brain as separate schema (brain.*) -- clean separation from Promaia public.*
- MuninnDB as cognitive memory sidecar with dual-write pattern (Hebbian strengthening, temporal decay, graph traversal)
- Web dashboard as display layer; Notion as agent workspace
- Superflat CSS skin with custom properties design system

**Issues Resolved:**
- psycopg2-binary build failure on Python 3.14 (used pre-built wheel)
- google-generativeai deprecated SDK (migrated to google-genai)
- ChromaDB local file dependency (replaced with pgvector)
- Agent SDK nested session error (run outside Claude Code)
- files.py KeyError on dict rows (index vs key access)

**Issues Deferred to v2:**
- Model routing (ROUTE-01-04) -- agents all use Opus, no cost optimization
- Mobile access (ACCESS-01) -- no Telegram, no phone interface
- Self-maintenance (MAINT-01-04) -- no dependency monitoring
- MuninnDB embeddings waiting on upstream fix (text-embedding-004 deprecated in v0.3.6-alpha)
- Gmail context loading in agents (Postgres fallback needed)
- SQL dialect bugs (jsonb operators, timestamp casting)

**Technical Debt:**
- unified_content SQLite view referenced in Postgres context (agents hit "no such table")
- Agent token tracking shows $0.00 in legacy mode
- MUNINN requirements marked "Planned" in traceability table (should be "Complete")
- Phase 04 sub-phases 4.2-4.6 completed without formal GSD plans/summaries
