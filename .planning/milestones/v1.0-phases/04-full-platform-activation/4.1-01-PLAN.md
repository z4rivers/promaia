Create `promaia/brain/muninn.py` — an async httpx REST client wrapping MuninnDB's REST API (port 8475). Do NOT use the muninndb Python SDK (broken on Python 3.14 — confirmed in research). httpx is already a project dependency.

**Class: `MuninnClient`**

Constructor:
- `base_url: str = "http://localhost:8475"` (configurable, default MuninnDB REST port)
- `vault: str = "zbrain-vault"` (single vault per locked decision)
- `timeout: float = 5.0` (aggressive timeout — MuninnDB is local, should be fast)
- Create `httpx.AsyncClient` with base_url, timeout, no auth headers (vault is `--public`)

Methods:

1. `async def health() -> bool` — GET `/api/health`, return True on 200, False on any exception. Used for startup checks and graceful degradation.

2. `async def write(concept: str, content: str, tags: list[str] | None = None, confidence: float = 0.9) -> str | None` — POST `/api/engrams` with `{"vault": self._vault, "concept": concept, "content": content, "tags": tags or [], "confidence": confidence}`. Return the ULID `id` string from response on success, None on failure. Log warning on failure but do NOT raise.

3. `async def write_batch(engrams: list[dict]) -> list[dict]` — POST `/api/engrams/batch` with `{"vault": self._vault, "engrams": engrams}`. Each engram dict has keys: concept, content, tags, confidence. Return list of `{"index": N, "id": "ULID", "status": "ok"}` results. Raise on failure (batch is used for seeding, not in hot path).

4. `async def activate(context: list[str], max_results: int = 10, threshold: float = 0.1) -> dict` — POST `/api/activate` with `{"vault": self._vault, "context": context, "max_results": max_results, "threshold": threshold}`. Return full response dict (contains `query_id`, `total_found`, `activations`, `latency_ms`, `brief`). Raise on failure.

5. `async def stats() -> dict` — GET `/api/stats?vault={self._vault}`. Return response dict. Useful for verifying embedder config (check `index_size > 0`).

6. `async def close()` — Call `self._client.aclose()`.

**Module-level lazy singleton: `get_muninn()`**

Match the existing `get_db()` / `get_vector_mgr()` pattern in mcp_server.py:
```python
_muninn: MuninnClient | None = None
_muninn_checked = False

async def get_muninn() -> MuninnClient | None:
    """Return MuninnDB client singleton, or None if unavailable."""
    global _muninn, _muninn_checked
    if not _muninn_checked:
        _muninn_checked = True
        client = MuninnClient()
        if await client.health():
            _muninn = client
            logger.info("MuninnDB connected (zbrain-vault)")
        else:
            logger.warning("MuninnDB unreachable at localhost:8475 — cognitive memory disabled")
            await client.close()
    return _muninn
```

Note: `get_muninn()` is async (unlike `get_db()`) because the health check is async. This is fine since all callers are async handlers. The `_muninn_checked` flag prevents repeated health checks on every call — check once, cache the result.

Add standard module imports: `httpx`, `logging`, `typing`. Add module docstring explaining this is the MuninnDB REST client and why the SDK is not used.

Do NOT generate embeddings client-side. MuninnDB handles embedding generation server-side via `MUNINN_GOOGLE_KEY`. The client only sends text.

async def _handle_activate(args: dict) -> list[TextContent]:
    """MuninnDB ACTIVATE cognitive retrieval."""
    context_text = args.get("context", "").strip()
    if not context_text:
        return [TextContent(type="text", text="Error: context is required.")]

    max_results = int(args.get("max_results", 10))
    threshold = float(args.get("threshold", 0.1))

    muninn = await get_muninn()
    if not muninn:
        return [TextContent(type="text", text="MuninnDB is not available. Use 'search' for pgvector-based retrieval.")]

    try:
        response = await muninn.activate(
            context=[context_text],
            max_results=max_results,
            threshold=threshold,
        )

        activations = response.get("activations", [])
        latency = response.get("latency_ms", 0)
        total = response.get("total_found", 0)

        if not activations:
            return [TextContent(type="text", text=f"No activations above threshold {threshold}. Try lowering the threshold.")]

        lines = [f"# ACTIVATE Results ({total} found, {latency:.1f}ms)\n"]
        for i, a in enumerate(activations, 1):
            score = a.get("score", 0)
            concept = a.get("concept", "")
            content = a.get("content", "")[:300]
            sc = a.get("score_components", {})
            dormant = " [dormant]" if a.get("dormant") else ""

            lines.append(f"**{i}.** (score: {score:.3f}){dormant}")
            lines.append(f"   Concept: {concept}")
            lines.append(f"   {content}")
            lines.append(f"   Components: semantic={sc.get('semantic_similarity', 0):.2f}, "
                         f"text={sc.get('full_text_relevance', 0):.2f}, "
                         f"hebbian={sc.get('hebbian_boost', 0):.2f}, "
                         f"decay={sc.get('decay_factor', 0):.3f}")
            lines.append("")

        # Include brief if available
        brief = response.get("brief", [])
        if brief:
            lines.append("## Brief")
            for b in brief:
                lines.append(f"- {b.get('text', '')}")

        return [TextContent(type="text", text="\n".join(lines))]

    except Exception as e:
        logger.error(f"activate failed: {e}", exc_info=True)
        return [TextContent(type="text", text=f"ACTIVATE error: {e}")]
```

import asyncio
from promaia.storage.postgres_db import get_postgres_db
from promaia.brain.muninn import MuninnClient

async def seed():
    db = get_postgres_db()
    rows = db.fetch_all("SELECT id, content, domain, tags FROM brain.memories ORDER BY id")
    print(f"Found {len(rows)} memories to seed")

    client = MuninnClient()
    healthy = await client.health()
    print(f"MuninnDB health: {healthy}")
    if not healthy:
        print("ERROR: MuninnDB not reachable. Is it running?")
        return

    engrams = []
    for row in rows:
        content = row["content"]
        tags = []
        if row.get("domain"):
            tags.append(row["domain"])
        if row.get("tags"):
            tags.extend(row["tags"])
        engrams.append({
            "concept": content[:100],
            "content": content,
            "tags": tags,
            "confidence": 0.9,
        })

    results = await client.write_batch(engrams)
    ok_count = sum(1 for r in results if r.get("status") == "ok")
    print(f"Seeded {ok_count}/{len(engrams)} engrams")
    await client.close()

asyncio.run(seed())
```
