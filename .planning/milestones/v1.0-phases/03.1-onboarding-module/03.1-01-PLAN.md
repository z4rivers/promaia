1. Add two tables to the END of schema.sql (after brain.modes):

**brain.onboarding_sessions:**
- id SERIAL PRIMARY KEY
- user_id TEXT DEFAULT 'default' (future multi-user support)
- status TEXT DEFAULT 'active' CHECK (status IN ('active', 'paused', 'complete'))
- started_at TIMESTAMPTZ DEFAULT NOW()
- last_activity TIMESTAMPTZ DEFAULT NOW()
- completed_at TIMESTAMPTZ
- metadata JSONB DEFAULT '{}' (stores things like interview_arc_phase: 'warm_up'|'current_state'|'gap_identification'|'commitment')

**brain.onboarding_progress:**
- id SERIAL PRIMARY KEY
- session_id INTEGER REFERENCES brain.onboarding_sessions(id) NOT NULL
- channel TEXT NOT NULL (values: 'interview', 'pc_scan', 'gmail', 'photos')
- status TEXT DEFAULT 'not_started' CHECK (status IN ('not_started', 'in_progress', 'complete', 'skipped'))
- started_at TIMESTAMPTZ
- completed_at TIMESTAMPTZ
- fields_populated INTEGER DEFAULT 0 (count of profile fields this channel contributed)
- notes TEXT (free-form notes about what was covered)
- UNIQUE(session_id, channel)

Add B-tree index on onboarding_sessions(user_id) and onboarding_progress(session_id).

2. Create promaia/brain/onboarding.py with these functions (all accept optional db parameter, same pattern as engine.py):

- `start_onboarding(user_id='default', db=None) -> dict`: Creates a new session row + 4 progress rows (one per channel, all 'not_started'). If an active session already exists, returns that instead. Returns {session_id, status, channels: [{channel, status}]}.

- `get_onboarding_status(user_id='default', db=None) -> dict`: Returns current onboarding state: {session_id, status, started_at, last_activity, channels: [{channel, status, fields_populated}], profile_coverage: {category: {total_fields: N, populated: M}}}. Profile coverage queries brain.profile grouped by category. Returns None if no active/paused session exists.

- `mark_channel_progress(session_id, channel, status, fields_populated=None, notes=None, db=None) -> bool`: Updates a channel's progress. When status='complete', sets completed_at=NOW(). Also updates session last_activity. Returns True on success.

- `get_profile_coverage(db=None) -> dict`: Queries brain.profile for field counts by category. Compares against the EXPECTED_FIELDS dict (derived from the research schema in Part 3) to show gaps. Returns {category: {expected: N, populated: M, missing: [field_names]}}.
