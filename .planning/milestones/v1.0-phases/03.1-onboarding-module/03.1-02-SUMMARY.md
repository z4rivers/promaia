## Decisions Made
- Used Windows registry query (`reg query`) instead of deprecated `wmic` for app detection -- more reliable and forward-compatible
- Gmail connector's `.service` API used directly for thread metadata fetching (format="metadata") instead of full sync_to_local
- PC scan confidence set to 0.6, Gmail scan to 0.5 -- email patterns are less direct evidence than git commit timestamps
- App categorization uses simple keyword matching (dev_tools, creative, productivity, communication, browsers) -- keeps it lightweight
- Gmail thread parsing extracts only: sender, recipients, subject, date, snippet -- never email body text
- `_run_async` helper handles both sync and async contexts for GmailConnector.connect()
