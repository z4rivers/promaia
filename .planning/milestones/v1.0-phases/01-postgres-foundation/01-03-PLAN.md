    The script should:

    1. **Read content from source tables.** After the libsql-changeover merge, content lives in libSQL/MuninnDB tables: `content_items`, `gmail_content`, `notion_journal` (if it exists), and any other content tables from the 586-line schema. Query each table for rows with non-null content.

    4. **Track progress.** Print progress: "Embedded X/Y items from content_items", etc. Use tqdm if available, fall back to print statements.

    5. **Be idempotent.** Use the UPSERT pattern (ON CONFLICT DO UPDATE) so the script can be re-run safely if interrupted. Check if embedding already exists before re-embedding (skip if `content_embeddings` already has a row for that `page_id` with a non-null embedding, unless `--force` flag is passed).

    6. **Support dry-run mode.** `--dry-run` flag counts how many items would be embedded without actually calling the embedding API.

    7. **Support `--force` flag** to re-embed everything even if embeddings already exist.

    8. **Script structure:**
       ```python
       #!/usr/bin/env python3
       """
       One-time migration: Re-embed all existing Promaia content with gemini-embedding-001.

       Usage:
           python scripts/migrate_embeddings.py              # Run migration
           python scripts/migrate_embeddings.py --dry-run    # Count items only
           python scripts/migrate_embeddings.py --force      # Re-embed everything
       """
       import argparse
       import time
       import sys
       import os

       # Add project root to path
       sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

       from promaia.storage.postgres_db import get_postgres_db
       from promaia.storage.vector_db import VectorDBManager

       def migrate_table(table_name, content_column, page_id_column, vdb, dry_run=False, force=False, delay=0.1):
           """Migrate embeddings from a single content table."""
           db = get_postgres_db()
           with db.get_connection() as conn:
               with conn.cursor() as cur:
                   cur.execute(f"SELECT {page_id_column}, {content_column} FROM {table_name} WHERE {content_column} IS NOT NULL AND {content_column} != ''")
                   rows = cur.fetchall()

           total = len(rows)
           embedded = 0
           skipped = 0

           for page_id, content in rows:
               if not force and vdb.check_exists(str(page_id)):
                   skipped += 1
                   continue
               if dry_run:
                   embedded += 1
                   continue
               try:
                   success = vdb.add_content(str(page_id), content, {"source_table": table_name})
                   if success:
                       embedded += 1
                   time.sleep(delay)
               except Exception as e:
                   print(f"  Error embedding {page_id}: {e}")

           return total, embedded, skipped
       ```

       - Any other content tables found in schema.sql
